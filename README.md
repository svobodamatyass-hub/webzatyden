# webzatyden

Produktový web pro profesionální tvorbu firemních webů do sedmi pracovních dní.

## Lokální vývoj

```bash
npm install
npm run dev
```

## Kontrola produkční verze

```bash
npm run build
npm run lint
```

Kontaktní adresa, právní údaje, ostré reference a formulářový backend se doplní před veřejným spuštěním.
